## Monthly Tasks (every month)

- [ ] Test smoke and CO detectors (press test button)
- [ ] Check fire extinguisher pressure gauge
- [ ] Replace HVAC air filter (1-inch filters: monthly; 4-inch: every 3 months)
- [ ] Clean dryer lint trap and check vent hose for lint buildup
- [ ] Run water in guest bathrooms / infrequently used sinks to prevent drain issues
- [ ] Check under sinks for any leaks
- [ ] Wipe down exterior of appliances (fridge, dishwasher, oven)

---

## Seasonal Schedule

### Spring (March–May)
**Do in March/April:**
- [ ] Clean gutters after winter
- [ ] Inspect roof for any winter damage
- [ ] Check exterior caulk around windows/doors — re-seal as needed
- [ ] Test outdoor water spigots and irrigation system
- [ ] Flush water heater (drain sediment)
- [ ] Reverse ceiling fan direction (counterclockwise for summer cooling)
- [ ] Deep clean windows inside and out
- [ ] Power wash driveway, walkways, deck/patio
- [ ] Fertilize lawn (first application)
- [ ] Service lawn mower before season starts
- [ ] Check weather stripping on all exterior doors
- [ ] Schedule HVAC tune-up for A/C before summer

### Summer (June–August)
**Do in June:**
- [ ] Check A/C performance
- [ ] Clean A/C condenser unit outside (hose off debris)
- [ ] Check window screens for holes/damage
- [ ] Fertilize lawn (second application, if applicable)

**Ongoing summer:**
- [ ] Water lawn during dry spells
- [ ] Keep gutters clear after summer storms

### Fall (September–November)
**Do in September/October:**
- [ ] Fertilize lawn (fall application)
- [ ] Drain and store garden hoses before first freeze
- [ ] Service heating system / HVAC tune-up
- [ ] Clean gutters after leaves fall
- [ ] Reverse ceiling fan direction (clockwise for winter heat circulation)
- [ ] Check roof condition before winter
- [ ] Blow out irrigation system before first hard freeze

### Winter (December–February)
**Do in December:**
- [ ] Know where your water main shutoff is
- [ ] Insulate exposed pipes in unheated areas if not already done
- [ ] Check roof after any ice or heavy snow event
- [ ] Deep clean oven

## Annual Tasks (pick a slow month — January or February works well)

- [ ] Have HVAC system professionally serviced
- [ ] Clean refrigerator coils (underneath/behind fridge)
- [ ] Test GFCI outlets in bathrooms, kitchen, garage
- [ ] Update home inventory for insurance purposes (photos of valuables)
- [ ] Review homeowner's insurance policy
